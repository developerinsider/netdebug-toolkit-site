LAN Scan

Discover active devices on your local network.

🖥

LAN Scan

lanscan

Input

  • Subnet (optional): CIDR like 192.168.1.0/24. Leave empty to use the detected local subnet.

Options

  • Scan Mode:
    • fast: quicker discovery using active TCP probing.
    • deep: broader discovery using ICMP + TCP with reverse DNS lookup.

Output

  • Active host list.
  • Progress and scan summary.
  • Discovery method notes.

Tips

  • Deep mode finds more devices but can take longer.
  • Very large subnets may be limited for performance and safety.

Deeplink

netdebug://lanscan?subnet=192.168.1.0/24&mode=deep

Tip: in the app, open the Export menu (the share icon) on this screen and choose Copy Deeplink to copy this link as a Universal Link with your current target and options already filled in.
