Lookup & Info

Whois

Look up registration and ownership-related data for a domain or IP.

📄

Whois

whois

Input

  • Domain or IP address.

Options

  • Lookup mode:
    • rdap (default): tries RDAP first and falls back to WHOIS if RDAP has no result.
    • whois: uses IANA WHOIS only, no RDAP fallback.

Output

  • Registrar/registry object details.
  • Status and lifecycle events.
  • Nameservers.
  • Source info (RDAP or WHOIS).

Tips

  • Availability of fields depends on registry and TLD policies.
  • For domains, nameserver details help diagnose delegation issues.
  • Use RDAP for structured output; use WHOIS when you specifically need classic WHOIS text output.

Deeplink

netdebug://whois?target=example.com&mode=rdap

Tip: in the app, open the Export menu (the share icon) on this screen and choose Copy Deeplink to copy this link as a Universal Link with your current target and options already filled in.
