Public IP + Geo/ASN

publicip

Input

  • No input required.

Output

  • Public (WAN) IP address.
  • ASN (network owner identifier).
  • ISP/provider.
  • Approximate city/region/country and coordinates.

Tips

  • Location is approximate and depends on provider data.
  • Useful for confirming VPN/proxy egress location.

Deeplink

netdebug://publicip?export=text

Tip: in the app, open the Export menu (the share icon) on this screen and choose Copy Deeplink to copy this link as a Universal Link with your current target and options already filled in.
