Speed / Latency Baseline

Capture a quick network performance snapshot — latency, jitter, download, and upload.

⚡

Speed / Latency Baseline

speed

Input

  • Download size preset (MB): 1, 2, 8, 16, 32, 64.
  • Upload size preset (MB): same set; default is 8 MB for both.

Output

  • Latency statistics (avg / min / max in ms).
  • Jitter snapshot (average latency variation in ms).
  • Download throughput (Mbps) with transfer size and elapsed time.
  • Upload throughput (Mbps) with transfer size and elapsed time.

Notes

  • This is a lightweight baseline, not a full benchmark suite.
  • Throughput and latency can vary by Wi-Fi quality, device load, route, and server conditions.
  • Uses Cloudflare speed-test endpoints over HTTPS.
  • Presets are capped at 64 MB to avoid endpoint payload rejections.

Deeplink

netdebug://speed?download=16&upload=8

Tip: in the app, open the Export menu (the share icon) on this screen and choose Copy Deeplink to copy this link as a Universal Link with your current target and options already filled in.
