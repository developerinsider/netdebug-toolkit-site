Calculate subnet details from CIDR input.

🧮

Subnet Calculator

subnet

Input

  • CIDR target (for example 192.168.1.10/24 or 2001:db8::1/64).

What it calculates

  • Network address.
  • Prefix / netmask details.
  • Address counts.
  • Usable host range (where applicable).
  • Gateway suggestions.

Tips

  • IPv4 and IPv6 are auto-detected from your input.
  • Make sure CIDR notation includes both address and prefix.

Deeplink

netdebug://subnet?target=192.168.1.0/24

Tip: in the app, open the Export menu (the share icon) on this screen and choose Copy Deeplink to copy this link as a Universal Link with your current target and options already filled in.
