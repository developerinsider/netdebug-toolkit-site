Run History & Trends

Every tool run and every automation step is saved on your device, so you can look back at what happened — and chart how latency, speed, and reachability change over time.

Run History

Open Run History from the home screen's Quick Access group, or from a saved host's tools screen to see just that host's runs. Each entry records the tool, target, time, duration, status (completed / cancelled / failed), the full output, and — for tools that produce numbers — structured metrics used by the charts.

  • Filter & search — narrow the list to one tool, or search by target.
  • Detail screen — view the complete saved output plus metadata, then Run Again (re-opens the tool with the same target and auto-runs), Export (text / PDF / image, the same share flow as a live run), or Delete.
  • Clear History — wipe all saved runs from the History screen's menu.
  • Automation runs — steps run inside an automation are saved too, tagged with the automation's name.

Trends

The Trends screen (from the History menu) draws a line chart of one metric over time, filterable by target and time range (7 / 30 / 90 days):

  • Download & Upload (Mbps) — from Speed/Latency Baseline and iperf3.
  • Latency & Jitter (ms), Packet Loss (%) — from Ping (and Speed latency).
  • Clock Offset (s) — from NTP Time Check.
  • HTTP Response (ms) — from HTTP(S) Check.

Each metric is scoped to the tools that produce it, so unrelated series never share an axis. Run a tool against the same target a few times and the trend takes shape.

Free, with tiered retention

Run History and Trends are free. How long runs are kept depends on the one-time purchases you already own — the highest tier applies (they don't stack):

What you ownRuns kept for
Nothing (free)3 days
Remove Ads7 days
Unlimited Automations14 days
Remove Ads + Unlimited Automations (Bundle)Unlimited

On the free and standalone tiers, runs older than the window are pruned automatically. The History screen footer shows your current window and a Keep runs longer shortcut to Settings → Purchases.

Private by design. Run history lives only on your device (SwiftData). It is never uploaded, synced, or shared anywhere. Deleting a run, clearing history, or reaching the retention window removes it for good.

On Apple TV

Apple TV has the same History and Trends screens. Delete a run from its context menu, and export a saved run's output over the local network as a QR code — scan it from a phone or laptop on the same Wi-Fi to download the file.
